# Block Editor

Notion 风格的 Obsidian 块编辑插件：块手柄、拖拽排序、多选、块类型转换与斜杠命令。仅桌面端。

## 功能

- **块手柄**：鼠标悬停或光标所在块的左侧显示六点拖拽手柄（Notion 样式），对应块浅色高亮
- **拖拽排序**：拖动块出现浮动预览与插入指示线（宽度取编辑器行宽）；拖到编辑区上下边缘自动滚动；拖到列表 / 引用 / Callout 正文右侧变为其子块（缩进 4 个字符，可用「缩进步长」调整），向左拖出自动降级缩进；拖到**普通段落 / 标题**右侧时自动把目标转为列表项（`- ` 前缀）并把被拖块缩进为其子项（Markdown 下只有列表项有父子结构）；拖到目标块左 / 右边缘快速与它合成两栏分栏；按住 **Alt 拖拽 = 复制到落点**；支持**跨分屏拖到其他文档**（移动 = 目标插入 + 源删除，Alt 同样为复制；同一文件的分屏按文档内移动处理）
- **拖动动作提示**：拖动时浮动预览上实时显示松手将执行的动作——移动 / 缩进为子块 / 复制（Alt）/ 移动到其他文档 / 复制到其他文档（Alt）/ 分栏 · 左 / 分栏 · 右，不会出现落点提示时（拖回自身等）不显示
- **多选**：Shift + 点击手柄把块加入 / 移出选区，可整组拖动、删除、复制、**批量转换类型**；Esc 退出多选
- **块菜单**：点击手柄弹出菜单——18 种类型互转（代码块带语言子菜单、Callout 带 12 种类型子菜单）、上/下方插入块、复制内容 / 块链接、创建副本（副本不带块 ID）、上移 / 下移、删除
- **斜杠命令**：正文输入 `/` 模糊搜索（子序列匹配 + 相关度排序，中英文可混查）快速转换块类型（代码块内自动禁用）
- **块 ID**：生成易拼写的 `^block-id`（正确处理代码块 / 列表等结构化块 ID 独立成行的规则）、复制块链接、一键清除全文块 ID（带确认框，防误触）
- **分栏**：Shift 多选相邻块后菜单「组合为分栏」（按空行切段，每段一栏）；阅读视图并排显示；Live Preview 渲染为并排分栏，**点击展开为源码编辑，点击外部自动收回**；分栏块菜单支持「添加一栏」「取消分栏」，可整体拖动 / 删除 / 跨文档搬运
- **命令面板**：`Alt+↑/↓` 移动块、缩进 / 反缩进、复制块链接、重复当前块、清除块 ID，以及每种类型独立的「转换为」命令

## 设置

设置 → Block Editor：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 显示块手柄 | 开 | 关闭后仅保留命令与斜杠入口 |
| 手柄跟随光标 | 开 | 关闭后仅在鼠标悬停时显示手柄 |
| 实验：实时预览自渲染分栏 | 关 | 开启后实时预览中分栏由插件自渲染（双击进入编辑）；关闭时显示原生嵌套 callout |
| 启用斜杠命令 | 开 | `/` 建议开关 |
| 拖拽自动滚动 | 开 | 拖到边缘自动滚动 |
| 缩进步长 | 自动 | 固定空格数或自动检测全文最小缩进；同时决定拖动嵌套插入的缩进（自动时为 4） |
| 默认栏间距 | 18 px | 分栏外壳未写 `gap=` 参数时的栏间距 |
| 默认圆角 | 5 px | 分栏外壳未写 `radius=` 参数时的栏圆角 |
| 默认垂直对齐 | 拉伸（等高） | 分栏外壳未写 `valign=` 参数时的栏垂直对齐方式 |
| 默认边框 | 关 | 分栏外壳未写 `border` 参数时是否显示栏边框 |
| 手柄尺寸 | 20 px | 编辑器左侧块手柄的大小 |
| 拖拽阈值 | 4 px | 按住手柄拖动的判定位移，小于该位移视为点击弹出块菜单 |

## 开发

```bash
npm install        # 安装依赖
npm run dev        # 监听构建（开发时用）
npm run build      # 类型检查 + 生产构建 → main.js
npm test           # 行为对照测试（未登记用例对照 scripts/legacy-main.cjs）
npm run test:update # 有意变更行为后重新生成预期差异基线 scripts/parity-baseline.json
```

源码在 `src/`，按职责分模块：`main`（入口装配）、`block-detect`（块识别与扫描缓存）、`handle`（手柄）、`drag`（拖拽）、`selection`（多选）、`block-menu`（菜单）、`convert`（类型转换）、`block-id`（块 ID）、`ops`（块操作）、`slash-suggest`（斜杠）、`commands`（命令注册）、`settings`（设置）。`scripts/legacy-main.cjs` 是重构前的单文件版本，仅作为 `npm test` 的行为基准保留，不要修改；相对它有意的行为变更记录在 `scripts/parity-baseline.json`（由 `npm run test:update` 生成）。

## 说明

- 从 0.2.0 起插件 id 为 `block-editor`（旧版为 `block-editor-mvp`），升级后需在「第三方插件」里重新启用一次
- `main.js` 为构建产物，请勿直接修改；改动请编辑 `src/` 后重新构建
